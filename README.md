# Mapdash

A world geography trainer. All 195 sovereign states, five drill modes, Warmer
(a hot-or-cold country hunt on a globe), adaptive drilling that goes after your
weak spots, and timed 1v1 races against a friend.

**Play it: <https://mapdashgame.web.app>**

Mirror: <https://aryansaksena0.github.io/mapdash/>

No accounts, no sign-ups, no ads, no server. Everything runs in your browser and
your progress stays in it.

No build step, no framework, no bundler. It's HTML, one JavaScript file, and a
map. You can open it, read it, and change it.

---

## What's in here

```
index.html              markup + all the styling
js/mapdash.js           the map engine, drill modes and 1v1
js/warmer.js            Warmer — the globe and the hot-or-cold hunt
data/world-data.js      239 country outlines + capitals, flags, borders
sw.js                   service worker (offline + instant loads)
manifest.webmanifest    installs to a phone home screen
```

## Run it right now

Double-click `index.html`. That's it — solo play works completely offline.

You land on a home screen: pick **Solo**, **Warmer** or **1v1**, or drop into Learn, Atlas
or Progress. The wordmark in the top-left always takes you back.

For 1v1 you need a real origin, because browsers won't let two `file://` tabs
talk to each other. Any static server does:

```bash
cd site
python3 -m http.server 8080
```

Then open <http://localhost:8080>. Create a match in one tab, paste the link
into a second tab, and race yourself. This works with **no backend at all** —
matches run over `BroadcastChannel` between tabs on the same machine.

## Publish it

**Cloudflare Pages** (free, fast, custom domains included):

1. Push this folder to a GitHub repo.
2. Cloudflare dashboard → Workers & Pages → Create → Pages → connect the repo.
3. Build command: *leave empty*. Build output directory: `/` (or `site` if you
   committed the parent folder).
4. Deploy. You get `something.pages.dev` in about a minute.

**Netlify** is the same idea, and you can skip git entirely — drag the folder
onto <https://app.netlify.com/drop>.

**A custom domain:** buy one (Cloudflare Registrar sells them at cost, roughly
$10/yr), then Pages → your project → Custom domains → add it. DNS is automatic
if the domain is already at Cloudflare.

At this point you have a live, installable, offline-capable site.

## Warmer

One country is hidden. Guess any country and it lights up on the globe in a
colour that says how far it is from the answer — pale blue is a world away, red
is nearly there, and anything sharing a border with the answer burns hottest.
There is no guess limit and no daily wait.

Spelling is deliberately forgiving: type `djobuti` and the list still offers
Djibouti, `burma` finds Myanmar, `drc` finds DR Congo. Enter takes the top
match, so a misspelling never costs you a turn.

The globe is drawn straight from `data/world-data.js`, the same file the map
uses, so it adds no extra download.

## How 1v1 works

Both players get the **same countries in the same order**, generated by the
host and sent over the wire at the starting whistle. You each move through the
list at your own pace — no waiting on your opponent. When the clock hits zero,
most found wins. A tie goes to whoever reached that score first.

One hint per country, and it only narrows to the continent. Nothing further.

Skip with `S` if you're stuck — the clock doesn't care about your feelings.

Messages travel over `BroadcastChannel` (
locally). The transport is swappable: both implementations speak the identical
message format, in `const Net` near the bottom of `mapdash.js`.

### Adding open matchmaking later

`schema.sql` ships a `queue` table and a `find_opponent()` function. Call it
with the player's settings; it either pairs you with someone already waiting
and hands back a join code, or parks you until someone else calls it. Wire a
"Find opponent" button to that RPC and feed the returned code straight into
`joinRace()`.

## Anti-cheat, honestly

Right now the browser decides whether an answer was right. For playing friends,
that's fine. If this ever gets competitive, move scoring server-side: seed a
`countries` table, have a Postgres function generate the question order, and
validate each guess with an RPC that compares against `order[index]`. The
client never learns the answer, and scores become trustworthy. The schema is
laid out so this slots in without touching the game code.

## Data and licensing

Country outlines come from **Natural Earth**, which is public domain — use it
for anything.

The country metadata (capitals, flags, borders, ISO codes) is derived from
[mledoze/countries](https://github.com/mledoze/countries), which is published
under the **Open Database License (ODbL)**. That's a share-alike license: if
you build a public product on it, attribute the source and keep derivative
databases under the same terms. Worth a read before you commercialize, and easy
to swap for a public-domain source if the terms don't suit you.
